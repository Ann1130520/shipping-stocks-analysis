# 🚢 航運雙雄情報戰情室 (長榮 2603 vs 陽明 2609)

專為台灣貨櫃航運雙雄打造的專業級股票與產業分析互動戰情網頁。

---

## 🌟 核心功能亮點

### 1. 📊 即時行情與戰情總覽 (Overview Dashboard)
- **跑馬燈行情看板**：監控長榮 (2603)、陽明 (2609)、SCFI 運價指數、布蘭特原油、蘇伊士繞道率。
- **雙雄 vs SCFI 歷史走勢對照圖**：支援「近1年」、「近2年」、「景氣大週期」視角切換，清晰呈現運價領先營收與股價波動的滯後性。
- **高低硫油價差 (Hi-5 Spread)**：即時分析脫硫塔改裝帶來的超額燃油紅利。

### 2. ⚔️ 雙雄深度對決 (Head-to-Head Comparison)
- **營運量化詳細對比表**：
  - 全球排名與總運力（長榮第 7 名 172 萬 TEU vs 陽明第 10 名 71.5 萬 TEU）。
  - 所屬航運聯盟（海洋聯盟 Ocean Alliance 續約至 2032 vs Premier Alliance 攜手 MSC）。
  - 自有船 vs 租船比率與脫硫塔裝載率（長榮 >80% vs 陽明 ~45%）。
  - 航線曝險分佈（美洲線 vs 歐洲地中海線比重）。
  - 財務指標（毛利率、預估 EPS、每股淨值 BVPS、股價淨值比 PB、現金殖利率）。
- **六大維度戰力雷達圖**：視覺化多維優劣勢。
- **航線運力部署對比圖**。
- **SWOT 與投資亮點分析卡片**。

### 3. ⚓ 貨櫃航運產業核心驅動分析 (Industry Deep-Dive)
- **三大決定性力量架構**：
  1. 名目供給：新船訂單比 (Orderbook-to-Fleet ~20.5%) 與拆船週期。
  2. 有效運力吸收：紅海危機繞行好望角吸收約 9.5%~11% 全球總運力。
  3. 環保法規壓力：IMO CII / EEXI 評級逼迫老船降速與加速淘汰。
- **四大主力航線運價趨勢圖**（歐洲線、美西線、美東線）。
- **全球供需平衡模擬模型**。
- **2025-2026 全球三大航運聯盟全新勢力圖**（Ocean Alliance vs Gemini vs Premier + MSC）。

### 4. 🌍 世界動態與航運咽喉戰略監控 (Geopolitics & Chokepoints)
- **紅海與曼德海峽 (Bab el-Mandeb)**：警戒狀態、繞行比例、單程延誤天數、保費及燃油附加費衝擊。
- **巴拿馬運河 (Panama Canal)**：乾季水位、每日通航槽位、加通湖吃水深度。
- **美東及墨西哥灣碼頭工會 (ILA)**：勞資協議進展、自動化爭議、美西港口轉單效應。
- **新加坡高低硫燃油價差追蹤**：估算長榮單月節省 2,500~3,000 萬美元燃油成本之利基。

### 5. 📰 航運即時情報與新聞中心 (News & Sentiment Center)
- 多維分類標籤：全部、地緣政治、運價指數、法說與財報、聯盟重組。
- 多空情緒標籤（偏多利多 / 中立監控 / 環保淘汰潮）。
- 關鍵字即時搜尋功能。
- 專門提煉「核心標的衝擊解讀」，直接將新聞事件連結到對長榮、陽明的獲利與股價影響。

### 6. 🧮 獲利與評價敏感度情境模擬器 (Scenario Calculator)
- 互動拉桿可自由調整：
  1. SCFI 綜合運價指數（1,200 ~ 4,000 點）
  2. 紅海繞行好望角比率（0% 蘇伊士復航 ~ 100% 全數繞道）
  3. 高低硫油價差 Hi-5 Spread（$50 ~ $250 / 噸）
  4. 預期現金股利配發率（30% ~ 65%）
- 即時動態運算並輸出長榮與陽明的：
  - 預估單季 EPS、預估年度 EPS
  - 預估每股股利與潛在現金殖利率
  - 動態本益比與專家操作策略指引。

## 🚀 如何快速開啟使用

### 方法一：直接點擊開啟（最簡單）
直接雙擊點開專案資料夾內的 `啟動戰情室.bat` 或直接用瀏覽器開啟 `index.html`。

### 方法二：透過 Python 本地伺服器開啟
在資料夾中執行：
```bash
python server.py
```
系統會自動在瀏覽器開啟 `http://localhost:8088/index.html`。
